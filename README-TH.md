# PdfCraft ภาษาไทย (ฉบับไม่เป็นทางการ)

PdfCraft ฉบับปรับปรุงให้ใช้งานภาษาไทยได้เต็มรูปแบบ ต่อยอดจาก [PdfCraft](https://github.com/storytold/pdfcraft) ของ ArtCraft
พัฒนาฉบับภาษาไทยโดย **Non.sittith**
**ฉบับนี้ไม่ใช่ฉบับทางการ** และไม่ได้อยู่ในความดูแลของผู้พัฒนา PdfCraft หากพบปัญหาในฉบับนี้ โปรดแจ้งที่ Issues ของ repository นี้ ไม่ใช่ที่โปรเจกต์ต้นฉบับ

> English: an unofficial Thai edition of PdfCraft (Thai UI, Thai text editing, TH Sarabun PSK and

## มีอะไรเพิ่มจากต้นฉบับ

- **หน้าจอภาษาไทย** เลือกได้ที่การตั้งค่า › ภาษา › ไทย
- **พิมพ์ข้อความภาษาไทยลงใน PDF ได้** (เพิ่มข้อความ และแก้ไขข้อความเดิม) สระและวรรณยุกต์วางตำแหน่งถูกต้อง
- **ฟอนต์ TH Sarabun PSK ในตัว** ทั้งตัวปกติ ตัวหนา ตัวเอียง และตัวหนาเอียง
- **ใช้ฟอนต์ที่ติดตั้งในเครื่องได้** เหมือน Word หรือ Acrobat
- **เมนูฟอนต์แบบใหม่:**
  - พิมพ์เพื่อค้นหาชื่อฟอนต์ได้
  - ฟอนต์ที่รองรับภาษาไทยมีป้าย **TH** กำกับ
  - เลื่อนเมาส์ผ่านชื่อฟอนต์เพื่อดูตัวอย่างก่อนเลือกได้
- **ขนาดตัวอักษรพิมพ์ตัวเลขเองได้** ตั้งแต่ 1–500 pt
- **กล่องข้อความปรับขนาดตามข้อความอัตโนมัติ**
- **กดลูกศรเพื่อขยับกล่องข้อความ** ทีละ 1 pt หรือกด Shift ค้างไว้เพื่อขยับทีละ 10 pt
- **ภาษาไทยได้ทุกเมนูที่พิมพ์ข้อความลง PDF:** กรอกและเซ็น (รวมวันที่แบบไทย) ความคิดเห็น ตราประทับ หัวกระดาษ/ท้ายกระดาษ ลายน้ำ แถบปิดทับ ช่องฟอร์ม สร้าง PDF จากข้อความ ชื่อในลายเซ็นดิจิทัล และลายเซ็นแบบพิมพ์
- **ตัวหนาและตัวเอียงสำหรับข้อความไทย**
- **คัดลอกกล่องข้อความ** ด้วย Ctrl+C / Ctrl+V หรือกด Ctrl ค้างแล้วลาก และกด Ctrl+Enter เพื่อจบการพิมพ์ได้
- **หัวกระดาษและท้ายกระดาษเลือกแบบอักษรได้** และมีปุ่มอัปเดต/เอาออกในแผงแก้ไข PDF
- **ป้ายอธิบายเครื่องมือไม่ถูกเมาส์บัง** ปรับตามขนาดเคอร์เซอร์ที่ตั้งไว้ใน Windows
- **เมนูแก้ไขข้อความและรูปภาพ** (คีย์ลัด **Ctrl+E**):
  - คลิก 1 ครั้งเพื่อเลือกกล่องข้อความหรือรูปภาพ แล้วลากเมาส์หรือกดลูกศรเพื่อขยับ
  - ดับเบิลคลิกที่กล่องข้อความเพื่อแก้ไขข้อความ
  - เลือกกล่องแล้วกด **Delete** เพื่อลบ กด Shift ค้างแล้วคลิกเพื่อเลือกหลายกล่อง แล้วลบพร้อมกันได้ ทั้งข้อความเดิม รูปภาพเดิม และกล่องที่เพิ่มหรือคัดลอกเอง (กด Ctrl+Z ครั้งเดียวได้กลับมาครบ)
- **ลายน้ำเลือกแบบอักษรได้** (รวม TH Sarabun PSK และฟอนต์ในเครื่อง) พร้อมตัวหนาและตัวเอียง
- **จัดลำดับชั้น** (คลิกขวา › จัดลำดับ หรือ Ctrl+] / Ctrl+[) สำหรับกล่องข้อความ รูปภาพ ความคิดเห็น และข้อความเดิมของไฟล์
- **เส้นช่วยจัดแนวแบบ Photoshop:** ลากหรือย่อขยายกล่องข้อความ รูป หรือย่อหน้าแล้วจะดูดเข้าแนวขอบและกึ่งกลางของหน้าและของสิ่งอื่นบนหน้า พร้อมเส้นและป้ายระยะ ΔX/ΔY (เส้นกึ่งกลางหน้าสีเขียว เส้นจัดแนวกับกล่องอื่นสีชมพู) กด Alt ค้างไว้ถ้าไม่ต้องการให้ดูด หรือปิดที่เมนูมุมมอง › เส้นช่วยจัดแนว / ดูดเข้าแนว
- **ผสานกล่องข้อความ:** เลือกหลายกล่องแล้วคลิกขวา › ผสานกล่องข้อความ ได้กล่องเดียวในที่เดิม (เหมาะกับไฟล์จาก Word ที่แยกคำละกล่อง) และ **แยกเป็นบรรทัด:** คลิกขวาที่กล่องหรือย่อหน้าหลายบรรทัด ได้กล่องละบรรทัดในที่เดิม
- **คัดลอกและวางทีละหลายชิ้น:** เลือกหลายกล่องหรือหลายรูปแล้ว Ctrl+C / Ctrl+V หรือคลิกขวา › คัดลอก / วาง / ลบ ได้ทีเดียวทั้งหมด รูปที่คัดลอกวางได้ขนาดเดิม และกด Ctrl ค้างแล้วลากเพื่อคัดลอกรูปหรือข้อความ
- **ไม้บรรทัดและเส้นตาราง:** เมนูมุมมอง › ไม้บรรทัด / เส้นตาราง ใช้หน่วยวัดตามการตั้งค่า กล่องที่ลากจะดูดเข้าเส้นตาราง (เส้นตารางแสดงบนจอเท่านั้น ไม่ติดไปในไฟล์หรือตอนพิมพ์)
- **เส้นไกด์จากไม้บรรทัดแบบ Photoshop:** ลากจากไม้บรรทัดบนหรือซ้ายลงมาบนหน้า ได้เส้นไกด์แนวนอนหรือแนวตั้ง พร้อมป้ายบอกตำแหน่ง เส้นจะดูดเข้ากึ่งกลางกระดาษแรงเป็นพิเศษ (เป็นสีเขียวขณะอยู่ที่กึ่งกลาง) และดูดเข้าขอบกระดาษและขอบวัตถุ กล่องที่ลากหรือย่อขยายก็ดูดเข้าเส้นไกด์ ลากเส้นกลับไปที่ไม้บรรทัดเพื่อลบ หรือเมนูมุมมอง › ล้างเส้นไกด์ (แสดงบนจอเท่านั้น ไม่บันทึกลงไฟล์)
- **ปุ่มจัดแนวจัดข้อความภายในกล่อง** ชิดซ้าย กึ่งกลาง ชิดขวา โดยกล่องไม่เปลี่ยนขนาด ใช้ได้ทั้งกล่องที่เพิ่มเองและย่อหน้าเดิมของไฟล์
- **ข้อความแนวตั้ง:** ช่อง "ทิศทางข้อความ" ในแผงจัดรูปแบบ เลือกได้ทั้งแบบเรียงทีละตัวอักษร (สระและวรรณยุกต์อยู่กับตัวอักษร) และแบบหมุน 90° ใช้ได้กับข้อความเดิมของไฟล์ด้วย (จะกลายเป็นกล่องข้อความใหม่ในที่เดิม)
- **กล่องข้อความที่เพิ่มเองขีดเส้นใต้และปรับระยะห่างบรรทัดได้**
- **ขีดเส้นใต้ข้อความเดิมของไฟล์แล้วเอาออกได้** เส้นใต้ไปกับข้อความ ทั้งตอนเปลี่ยนตัวหนา ลบ หรือย้าย และเอาออกได้แม้แค่คลิกเลือกกล่องไว้
- **คัดลอก/วาง** ความคิดเห็นและรูปภาพ วางรูปจากคลิปบอร์ดหรือไฟล์ใน Explorer และ**ลากข้ามหน้า**ได้ (กด Ctrl ค้างเพื่อคัดลอกข้ามหน้า)
- **หน้าต่างพิมพ์กด Enter เพื่อพิมพ์ได้เลย**
- **ชี้เมาส์แล้วเห็นผลก่อนเลือก** ในแผงจัดรูปแบบข้อความ: ฟอนต์ ขนาด สี ตัวหนา ตัวเอียง และขีดเส้นใต้ ถ้าไม่คลิกก็กลับเป็นแบบเดิม
- **จัดรูปแบบหลายกล่องพร้อมกัน:** กด Shift ค้างแล้วคลิกเลือกหลายกล่อง แผงจัดรูปแบบจะเปลี่ยนให้ทุกกล่องในครั้งเดียว
- **ตัวคัดวางรูปแบบ (Format painter):** เลือกกล่องต้นแบบ กดปุ่มแปรง แล้วคลิกกล่องอื่นเพื่อใช้รูปแบบเดียวกัน (ดับเบิลคลิกที่ปุ่มเพื่อใช้ต่อหลายกล่อง กด Esc เพื่อหยุด)
- **บอกชื่อฟอนต์ที่ไม่มีในเครื่อง** เมื่อแก้ข้อความแล้วต้องใช้ฟอนต์อื่นแทน
- **ข้อความกรอกและเซ็น และกล่องข้อความความคิดเห็น เลือกฟอนต์ได้** พร้อมตัวหนาและตัวเอียง (กรอกและเซ็น: ปุ่ม "Aa" ในแถบเครื่องมือ · กล่องข้อความ: คลิกขวา › คุณสมบัติ)
- **กด Shift ค้างตอนวาดรูปทรง** ได้สี่เหลี่ยมจัตุรัส วงกลม หรือเส้นตรงทุก 45 องศา เหมือน Word
- **ไอคอนแมวบนพื้นแดง** ไม่สับสนกับแอปทางการ
- **Ctrl+T** เพื่อเพิ่มข้อความ และ **Ctrl+E** เพื่อแก้ไขข้อความและรูปภาพ (มีหน้าต่างเคล็ดลับตอนเปิดเอกสารแรก เปิดอีกได้ที่เมนูวิธีใช้ › เคล็ดลับการแก้ไขข้อความ)
- **แจ้งเตือนอัปเดต:** ตอนเปิดโปรแกรมจะถาม GitHub ว่ามีรุ่นใหม่ของฉบับภาษาไทยไหม (ไม่ใช่รุ่นของทางการ) กด "อัปเดตและเปิดใหม่" แล้วโปรแกรมจะดาวน์โหลด ตรวจ SHA-256 ติดตั้ง และเปิดใหม่ให้ ถามอย่างมากวันละครั้ง และติ๊ก "ไม่ต้องเตือนรุ่นนี้อีก" ได้ ปิดการตรวจได้ที่การตั้งค่า รุ่น portable จะเปิดหน้าดาวน์โหลดแทน
- **ลากหรือย่อขยายรูปแล้วเห็นแค่ตัวรูป** ไม่มีพื้นหลังของหน้าติดมา และลากรูปเดิมในไฟล์ไปวางหน้าอื่นได้
- **หมุนลูกกลิ้งเมาส์บนช่องขนาดตัวอักษร** เพื่อปรับทีละ 1 pt ได้ แม้คลิกอยู่ในช่อง
- **OCR ภาษาไทย:** สแกน & OCR › จดจำข้อความ เลือกภาษาไทย อ่านตัวพิมพ์ไทยและอังกฤษในเครื่อง ไม่ส่งเอกสารออกนอกเครื่อง (ใช้โมเดล PaddleOCR สัญญาอนุญาต Apache-2.0)

## ดาวน์โหลดและติดตั้ง (Windows 64 บิต)

ดาวน์โหลดจากหน้า [Releases](../../releases) ได้ 2 แบบ:

- **ตัวติดตั้ง** `…-windows-x64.msi` ดับเบิลคลิกเพื่อติดตั้งลงเครื่อง หน้าตัวติดตั้งเป็นภาษาไทย เลือกได้ว่าติดตั้ง "เฉพาะฉัน" หรือ "ทุกคนในเครื่อง" (แบบหลังต้องใช้สิทธิ์ผู้ดูแลระบบ) มีทางลัดใน Start menu และบนเดสก์ท็อป ติดตั้งทับรุ่นเก่าได้เลย
  ถ้าเครื่องมี PdfCraft ตัวทางการติดตั้งอยู่ ตัวติดตั้งนี้จะติดตั้งทับแทนที่ ถ้าตัวทางการเป็นเวอร์ชันใหม่กว่า ให้ถอนการติดตั้งตัวทางการก่อน
- **แบบ portable** `…-portable.zip` แตกไฟล์ไว้ที่ใดก็ได้ (เช่น แฟลชไดรฟ์) แล้วเปิด `pdfcraft.exe` ไม่ต้องติดตั้ง
  การตั้งค่าเก็บไว้ในโฟลเดอร์ `PdfCraftData` ข้างไฟล์โปรแกรม

เลือกหรือเปลี่ยนภาษาของหน้าจอได้ที่การตั้งค่า › ภาษา

**หมายเหตุ:** ไฟล์โปรแกรมในฉบับนี้ไม่มีลายเซ็นดิจิทัล Windows SmartScreen หรือโปรแกรมป้องกันไวรัสจึงอาจเตือนหรือบล็อกตอนเปิดครั้งแรก
ตรวจสอบได้ว่าไฟล์ไม่ถูกแก้ไขระหว่างทางโดยเทียบค่า SHA-256 ที่ระบุในหน้า Release

## ถ้าแก้ไขข้อความแล้วแก้ไม่ได้ หรือตัวอักษรเพี้ยน

PDF ส่วนใหญ่ (เช่น ที่บันทึกจาก Word) ไม่ได้ฝังฟอนต์มาทั้งชุด มีมาแค่ตัวอักษรที่ใช้ในเอกสาร เวลาแก้ไขข้อความเดิม
โปรแกรมจึงต้องหาฟอนต์ตัวเต็มจากในเครื่อง:

- **ถ้าเครื่องมีฟอนต์ชื่อเดียวกับในเอกสาร** ข้อความที่แก้จะใช้ฟอนต์นั้น หน้าตาเหมือนเดิม
- **ถ้าไม่มี** โปรแกรมจะใช้ TH Sarabun PSK แทน ข้อความที่แก้จึงอาจดูต่างจากส่วนอื่นของเอกสาร

ถ้าแก้แล้วขึ้นข้อผิดพลาด ตัวอักษรเพี้ยน หรือฟอนต์ไม่เหมือนเดิม ให้ลอง **ติดตั้งฟอนต์ที่เอกสารใช้ลงในเครื่อง** แล้วเปิดโปรแกรมใหม่

- **ดูชื่อฟอนต์ที่เอกสารใช้:** เปิด คุณสมบัติเอกสาร (Ctrl+D) › แท็บ "แบบอักษร" ชื่อที่ขึ้นต้นด้วยตัวอักษร 6 ตัวกับเครื่องหมาย + (เช่น `ABCDEF+AngsanaNew`) หมายถึงฟอนต์ที่ฝังมาไม่ครบชุด ชื่อฟอนต์คือส่วนหลังเครื่องหมาย +
- **ฟอนต์ไทยที่มากับ Windows:** บางตัว เช่น Angsana New, Cordia New, Browallia New ไม่ได้ติดตั้งมาใน Windows 10/11 ให้เพิ่มได้ที่ การตั้งค่า › แอป › ฟีเจอร์เพิ่มเติม (Optional features) › เพิ่ม "Thai Supplemental Fonts"

## Build เอง

ต้องมี [Rust](https://rustup.rs) และ Visual Studio Build Tools (เลือก workload C++) จากนั้นสั่ง:

```powershell
powershell -ExecutionPolicy Bypass -File thai\build-windows.ps1
```

สคริปต์จะดาวน์โหลดชุดฟอนต์ craft-fonts รุ่นเดียวกับที่ PdfCraft ใช้ เพิ่ม TH Sarabun PSK จากโฟลเดอร์ `thai/fonts` แล้ว build ไฟล์ออกมาที่ `target\x86_64-pc-windows-msvc\release`

ถ้าต้องการทำตัวติดตั้งและไฟล์ portable ด้วย ให้ติดตั้ง WiX v5 (`winget install WiXToolset.WiXCLI --version 5.0.2.0`) แล้วสั่ง:

```powershell
powershell -ExecutionPolicy Bypass -File thai\package-windows.ps1
```
