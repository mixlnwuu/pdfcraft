พิมพ์ภาษาไทยลงใน PDF

เพิ่มข้อความใหม่หรือแก้ข้อความเดิมเป็นภาษาไทย สระและวรรณยุกต์วางตำแหน่งถูกต้อง ค้นหาและคัดลอกข้อความได้

เมนูภาษาไทยทั้งหมด

หน้าจอและเมนูเป็นภาษาไทยทั้งโปรแกรม เลือกหรือเปลี่ยนภาษาได้ที่ การตั้งค่า › ภาษา

ฟอนต์ TH Sarabun PSK ในตัว

มีครบทั้งตัวปกติ ตัวหนา ตัวเอียง และตัวหนาเอียง และใช้ฟอนต์ที่ติดตั้งในเครื่องได้เหมือน Word

กรอกและเซ็นเอกสาร

กรอกแบบฟอร์ม ใส่วันที่แบบไทย ลายเซ็นแบบพิมพ์ และชื่อภาษาไทยในลายเซ็นดิจิทัล

ความคิดเห็นและตราประทับ

เขียนโน้ต คำบรรยาย ตราประทับ หัวกระดาษ ท้ายกระดาษ และลายน้ำเป็นภาษาไทยได้

จัดการหน้าและไฟล์

รวมไฟล์ จัดเรียง หมุน ลบหน้า บีบอัด PDF ใส่รหัสผ่าน และปิดทับข้อมูลที่ไม่ต้องการให้เห็น

ใช้งานง่ายเหมือน Word

คัดลอกกล่องข้อความด้วย Ctrl+C / Ctrl+V จัดลำดับชั้น มีเส้นช่วยจัดกึ่งกลางหน้า และลากของข้ามหน้าได้

OCR ภาษาไทย

เปลี่ยนไฟล์สแกนให้ค้นหา คัดลอก และแก้ข้อความไทยได้ ทำงานในเครื่องทั้งหมด

ฟรี ออฟไลน์ เป็นส่วนตัว

ไม่ต้องสมัครบัญชี ใช้งานได้โดยไม่ต้องต่ออินเทอร์เน็ต ไฟล์ไม่ถูกส่งออกไปที่ไหน เป็นโปรแกรมโอเพนซอร์ส (ตอนเปิดโปรแกรมจะถาม GitHub ว่ามีรุ่นใหม่ไหม ปิดได้ที่การตั้งค่า)

ฟรีตลอดไปไม่มีโฆษณา ไม่ต้องสมัครบัญชี
ทำงานออฟไลน์ไฟล์ของคุณไม่ถูกส่งออกนอกเครื่อง
โอเพนซอร์สโค้ดเปิดให้ตรวจสอบบน GitHub

ได้คมชัดเหมือนต้นฉบับ

พิมพ์ แก้ และจัดหน้าเอกสารภาษาไทยได้ในโปรแกรมเดียว

  • สระและวรรณยุกต์อยู่ถูกที่ ไม่ลอย ไม่ซ้อน
  • ฟอนต์ TH Sarabun PSK สำหรับหนังสือราชการ
  • ตัวเลขไทย วันที่แบบไทย และข้อความแนวตั้ง
  • ธีมมืดและสว่าง สลับได้ในโปรแกรม

ต่างจาก PdfCraft ตัวทางการอย่างไร

ฉบับภาษาไทยมีทุกอย่างของ PdfCraft ทางการรุ่น v0.18.2 และเพิ่มสิ่งเหล่านี้

เรื่องPdfCraft ทางการPdfCraft ภาษาไทย
หน้าจอและเมนูมีภาษาไทยแล้ว (ใช้คำแปลที่ฉบับนี้ส่งให้)ภาษาไทยครบทุกข้อความ รวมเมนูที่มีเฉพาะฉบับนี้
พิมพ์ภาษาไทยด้วยเมนู "เพิ่มข้อความ"ได้ (ฟอนต์ Noto Sans Thai)ได้ เลือกฟอนต์ไทยได้ ทั้ง TH Sarabun PSK และฟอนต์ในเครื่อง พร้อมตัวหนาและตัวเอียง
ภาษาไทยในเมนูอื่นที่เขียนข้อความลง PDFไม่ได้ หรือขึ้นเป็นเครื่องหมาย ? (ทดสอบกับรุ่น v0.13.0: หัวกระดาษ ลายน้ำ และชื่อในลายเซ็นไม่รับภาษาไทย กรอกและเซ็นกับความคิดเห็นขึ้นเป็น ?)ได้ทุกเมนู: กรอกและเซ็น (วันที่แบบไทย) ความคิดเห็น คำบรรยาย ตราประทับ หัวกระดาษ/ท้ายกระดาษ ลายน้ำ แถบปิดทับ ช่องฟอร์ม สร้าง PDF จากข้อความ และชื่อในลายเซ็น
ฟอนต์ TH Sarabun PSKไม่มีมีในตัว ครบ 4 แบบ
ใช้ฟอนต์ที่ติดตั้งในเครื่องได้เฉพาะตอนแก้ข้อความเดิม และเฉพาะฟอนต์ที่มีสัญญาอนุญาตแบบเปิด ไม่มีช่องค้นหา (เพิ่มข้อความใช้ได้แค่ Helvetica, Times, Courier)ได้ทุกฟอนต์ในเครื่อง ทั้งเพิ่มข้อความและแก้ข้อความเดิม เหมือน Word มีช่องค้นหาชื่อฟอนต์ และป้าย TH บอกฟอนต์ที่รองรับภาษาไทย
แบบอักษรของหัวกระดาษ/ท้ายกระดาษ และลายน้ำหัวกระดาษเลือกได้ 3 แบบ (Helvetica, Times, Courier) ลายน้ำ Helvetica อย่างเดียว ไม่มีตัวหนาหรือตัวเอียงเลือกฟอนต์ไทยหรือฟอนต์ในเครื่องได้ พร้อมตัวหนาและตัวเอียง
ชี้เมาส์แล้วเห็นผลก่อนเลือกไม่มีในแผงจัดรูปแบบข้อความ ชี้ที่ฟอนต์ ขนาด สี ตัวหนา ตัวเอียง หรือขีดเส้นใต้ ข้อความจะเปลี่ยนให้ดูก่อน ถ้าไม่คลิกก็กลับเป็นแบบเดิม
ขนาดตัวอักษรพิมพ์ตัวเลขเองหรือเลือกจากรายการพิมพ์เองได้ตั้งแต่ 1–500 pt เลือกจากรายการ หรือหมุนลูกกลิ้งเมาส์ พร้อมดูตัวอย่างก่อน
แก้ไขข้อความเดิมในไฟล์คลิกครั้งเดียวเปิดแก้ทันทีคลิกครั้งเดียวเลือก ลากหรือกดลูกศรเพื่อขยับ ดับเบิลคลิกเพื่อแก้ (คล้าย Word) และกด Ctrl+E เพื่อเข้าโหมดแก้ไขข้อความและรูปภาพ
จัดลำดับชั้น (หน้าสุด/หลังสุด)ไม่มีมี ใช้กับกล่องข้อความ รูปภาพ ความคิดเห็น และข้อความเดิมของไฟล์ (คลิกขวา › จัดลำดับ หรือ Ctrl+] / Ctrl+[)
เส้นช่วยจัดแนวไม่มีแบบ Photoshop: ลากแล้วดูดเข้าแนวขอบและกึ่งกลางของหน้าและของสิ่งอื่นบนหน้า ทั้งตอนย้ายและย่อขยาย พร้อมเส้นและป้ายระยะ (เส้นกึ่งกลางหน้าสีเขียว) กด Alt ค้างเพื่อไม่ให้ดูด หรือปิดที่เมนูมุมมอง
ผสานและแยกกล่องข้อความไม่มีเลือกหลายกล่องแล้วคลิกขวาผสานเป็นกล่องเดียวในที่เดิม หรือแยกย่อหน้าเป็นกล่องละบรรทัด เหมาะกับไฟล์จาก Word ที่แยกคำละกล่อง
ไม้บรรทัดและเส้นตารางไม่มีมี (เมนูมุมมอง) กล่องที่ลากดูดเข้าเส้นตาราง เส้นตารางแสดงบนจอเท่านั้น
เส้นไกด์จากไม้บรรทัดไม่มีลากจากไม้บรรทัดแบบ Photoshop พร้อมป้ายบอกตำแหน่ง ดูดเข้ากึ่งกลางกระดาษแรงเป็นพิเศษ (สีเขียว) และขอบวัตถุ กล่องที่ลากดูดเข้าเส้นไกด์
ข้อความแนวตั้งไม่มีเรียงทีละตัวอักษร (สระและวรรณยุกต์อยู่กับตัวอักษร) หรือหมุน 90° ใช้กับข้อความเดิมของไฟล์ได้ด้วย
ขีดเส้นใต้และระยะห่างบรรทัดทำได้เฉพาะข้อความเดิมของไฟล์ และเส้นใต้ค้างอยู่เมื่อลบหรือเปลี่ยนรูปแบบข้อความทำได้ทั้งกล่องที่เพิ่มเองและข้อความเดิม เส้นใต้ไปกับข้อความทั้งตอนลบ ย้าย หรือเปลี่ยนรูปแบบ
คัดลอกความคิดเห็นและลากข้ามหน้าไม่มีคัดลอก/วางความคิดเห็นได้ทุกแบบ ลากกล่องข้อความ รูปภาพ (รวมรูปเดิมในไฟล์) และความคิดเห็นไปหน้าอื่นได้ (Ctrl ค้าง = คัดลอกข้ามหน้า) และวางรูปจากโปรแกรมอื่นด้วย Ctrl+V
สั่งพิมพ์บน Windowsไฟล์ที่มีข้อความแบบ Type 3 ทำให้โปรแกรมปิดตัวตอนพิมพ์ และรูปที่พิมพ์เป็นภาพถูกย่อเหลือราว 96 dpi จนเบลอไฟล์แบบนั้นพิมพ์เป็นภาพให้อัตโนมัติ ไม่ปิดตัว และส่งรูปความละเอียดเต็มไปที่เครื่องพิมพ์
หน้าต่างพิมพ์ต้องคลิกปุ่มพิมพ์กด Enter เพื่อพิมพ์ได้เลย
ป้ายอธิบายเครื่องมืออาจถูกเคอร์เซอร์บังเมื่อตั้งเคอร์เซอร์ใหญ่ปรับตำแหน่งตามขนาดเคอร์เซอร์ที่ตั้งไว้ใน Windows
ตรวจหาการอัปเดตตรวจเองตอนเปิดโปรแกรม และเสนอให้อัปเดตเป็นรุ่นทางการตรวจตอนเปิดโปรแกรม แจ้งเฉพาะรุ่นใหม่ของฉบับภาษาไทย กด "อัปเดตและเปิดใหม่" ได้เลย ถามอย่างมากวันละครั้ง ติ๊ก "ไม่ต้องเตือนรุ่นนี้อีก" ได้ ปิดการตรวจได้ที่การตั้งค่า ไม่มีทางถูกแทนที่ด้วยตัวทางการ
OCR อ่านภาษาไทยจากไฟล์สแกนอ่านได้เฉพาะภาษาอังกฤษอ่านตัวพิมพ์ไทยและอังกฤษในเครื่อง ไม่ส่งเอกสารออกนอกเครื่อง
จัดรูปแบบข้อความทีละกล่องเลือกหลายกล่องแล้วเปลี่ยนพร้อมกันได้ และมีตัวคัดวางรูปแบบ (Format painter)
เลือกฟอนต์ในกรอกและเซ็น และกล่องข้อความความคิดเห็นไม่มีเลือกฟอนต์ไทย ฟอนต์ในเครื่อง ตัวหนา และตัวเอียงได้

เปรียบเทียบกับ PdfCraft ทางการรุ่น v0.18.2 ตามโค้ดของทั้งสองฉบับและการทดลองใช้ตัวทางการ ถ้าทางการเพิ่มสิ่งเหล่านี้ในรุ่นถัดไป ตารางนี้อาจเปลี่ยน

ดาวน์โหลดและติดตั้ง

รุ่น 0.20.0-th.1 สำหรับ Windows 10/11 แบบ 64 บิต

  1. เปิดหน้า ดาวน์โหลดรุ่นล่าสุด แล้วเลื่อนลงไปที่หัวข้อ Assets
  2. แบบติดตั้ง: กดไฟล์ที่ลงท้ายด้วย -windows-x64.msi แล้วดับเบิลคลิกเพื่อติดตั้ง ตัวติดตั้งเป็นภาษาไทย จะถามว่าให้ติดตั้งสำหรับตัวเองคนเดียว (ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ) หรือทุกคนในเครื่อง ถ้าเคยติดตั้งรุ่นก่อนไว้แล้ว ให้เลือกทุกคนในเครื่องเพื่ออัปเดตตัวเดิม จะมีทางลัดใน Start menu และบนเดสก์ท็อป
  3. แบบไม่ต้องติดตั้ง: กดไฟล์ที่ลงท้ายด้วย -portable.zip แตกไฟล์ไว้ที่ใดก็ได้ (เช่น แฟลชไดรฟ์) แล้วเปิด pdfcraft.exe
  4. เปิดโปรแกรม จะเป็นภาษาไทยทันที ลากไฟล์ PDF มาวางในโปรแกรมเพื่อเริ่มแก้ไขได้เลย

แก้ข้อความเดิมแล้วตัวอักษรเพี้ยน หรือฟอนต์ไม่เหมือนเดิม

PDF ส่วนใหญ่ (เช่น ที่บันทึกจาก Word) ฝังฟอนต์มาไม่ครบชุด โปรแกรมจึงต้องหาฟอนต์ตัวเต็มจากในเครื่อง ถ้าไม่มีจะใช้ TH Sarabun PSK แทน วิธีแก้คือติดตั้งฟอนต์ที่เอกสารใช้ลงในเครื่อง แล้วเปิดโปรแกรมใหม่

  • ดูชื่อฟอนต์ได้ที่ คุณสมบัติเอกสาร (Ctrl+D) › แท็บ "แบบอักษร"
  • ฟอนต์ Angsana New, Cordia New, Browallia New เพิ่มได้ที่ การตั้งค่า Windows › แอป › ฟีเจอร์เพิ่มเติม › "Thai Supplemental Fonts"
ต่างจาก PdfCraft ตัวทางการอย่างไร

ฉบับนี้ต่อยอดจาก PdfCraft รุ่น v0.18.2 แล้วเพิ่มการพิมพ์และแก้ข้อความภาษาไทยในทุกเมนู ฟอนต์ TH Sarabun PSK ในตัว เมนูฟอนต์ที่ค้นหาได้ และปรับการใช้งานให้คล้าย Word ถ้าติดตั้งทับตัวทางการ จะใช้แทนกันได้เลย ดูรายการทั้งหมดได้ที่ ตารางเปรียบเทียบ

อ่านข้อความไทยจากไฟล์สแกน (OCR) ได้ไหม

ได้แล้ว เมนู สแกน & OCR › จดจำข้อความ เลือกภาษาไทย อ่านตัวพิมพ์ไทยและอังกฤษในเครื่อง ไม่ส่งเอกสารออกนอกเครื่อง ลายมือยังอ่านไม่ได้
