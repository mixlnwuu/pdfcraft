# PdfCraft Thai Edition (unofficial)

**ภาษาไทย: อ่านรายละเอียด วิธีดาวน์โหลด และวิธีใช้งานได้ที่ [README-TH.md](README-TH.md)**

An unofficial edition of [PdfCraft](https://github.com/storytold/pdfcraft), the open-source PDF
application, with full Thai support:

- a Thai user interface;
- Thai text that shapes correctly when adding or editing text in a PDF;
- TH Sarabun PSK built in, plus every embeddable font installed on the computer;
- a searchable font menu with Thai-support marks and hover previews, typed font sizes, text boxes
  that fit their text, and arrow-key nudging of the selected text box.

Downloads for Windows are on the [Releases](../../releases) page. To build it yourself, run
`thai\build-windows.ps1` (see [README-TH.md](README-TH.md)).

The Thai edition is developed by Non.sittith.

This edition is based on PdfCraft by the ArtCraft team (upstream release v0.14.0). It is not made,
endorsed or supported by the ArtCraft team. Please report problems with it here, not upstream.
As the ArtCraft brand terms require of modified versions, the ArtCraft logos have been removed from
this repository and from the program.
